### Item 2: P1 — 同批发布 (V2+V3+N11, N4+N7)

- [x] **V2**: `scripts/audit.py:100-101` — in `check_orphan_pages`, change `if rel.name == "index.md": continue` so it only skips `all_pages.add(str(rel))` but STILL harvests wikilinks from index.md (index.md's links should count as incoming links for orphan detection)
- [x] **V3**: `scripts/audit.py:108-110` — fix orphan identity comparison. Currently compares `page_stem` (bare stem like "marginalia") and `str(page)` (like "concepts/marginalia.md") against `all_links`. Path-style links like `[[concepts/marginalia]]` never match either. Fix: also compare `str(Path(page).with_suffix(''))` (e.g., "concepts/marginalia") against `all_links`
- [x] **N11**: `scripts/audit.py:117` — `suggested_action` uses bare `page_stem` (e.g., "marginalia"), should use path-without-extension (e.g., "concepts/marginalia") to match path-style wikilink convention
- [x] **N4+N7**: `scripts/audit.py:51-68` — add containment check in `resolve_wikilink`. After checking `c.exists()`, also verify `c.resolve()` is relative to `root` or any `external_kb_dirs` path. Do NOT remove `root.parent` candidates — that would break v0.2.1 `--external-kb-dirs` cross-KB link design. Instead, keep all candidates but add `is_relative_to(root)` validation on the resolved path
