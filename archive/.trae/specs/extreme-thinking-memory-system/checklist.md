# Checklist

## 极致思考记忆系统检查清单

### 页面类型检查

- [ ] Concept 页面占比是否在 40-50%（正常范围）
- [ ] 是否存在从未被引用的孤立 Concept 页面
- [ ] Entity 页面是否有明确的定位信息
- [ ] Source 页面是否有摘要和核心知识点

### 质量检查

- [ ] 所有 [[wikilink]] 是否指向真实文件（断链 = 0）
- [ ] index.md 是否覆盖所有页面
- [ ] 每个页面是否有定义段落
- [ ] 是否存在薄页面（只有骨架无实质内容）

### 驱动检查

- [ ] CLAUDE.md 中是否包含协议标记段
- [ ] 协议版本是否与 schema/ 一致
- [ ] AI 是否在会话开始时自动读 index.md

### 工作流检查

- [ ] 摄入工作流是否按 schema/ingest.md 执行
- [ ] 每次摄入后是否更新 index.md
- [ ] 每次摄入后是否回写 progress.md
- [ ] 是否定期运行 audit.py
